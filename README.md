# 📘 Atividade: Personalize sua experiência com o GitHub Copilot

## 🎯 Objetivo

Explorar como personalizar sua experiência com o GitHub Copilot seguindo as orientações do exercício.

## 📝 Tarefas

### 🛠️ Complete o exercício

#### Descrição

Acesse o [exercício no GitHub](https://github.com/treinamentos-mgi/skills-customize-your-github-copilot-experience-carlosgold/issues/1) e siga as etapas para personalizar sua experiência com o Copilot. Faça a atividade no seu ritmo.

#### Requisitos

Ao concluir, você deve:

- Seguir as orientações apresentadas no exercício.
- Aplicar as personalizações solicitadas ao GitHub Copilot.
- Conferir as alterações realizadas no repositório.
